Annotated Bibliography

Research sources used in this tutorial on mobile computer vision and obstacle detection for blind and low-vision users.

[1] Bastidas-Guacho et al. (2025)

Citation:
Bastidas-Guacho, G. K., Paguay Alvarado, M. A., Moreno-Vallejo, P. X., Moreno-Costales, P. R., Ocaña Yanza, N. S., & Troya Cuestas, J. C. (2025). Computer Vision-Based Obstacle Detection Mobile System for Visually Impaired Individuals. Multimodal Technologies and Interaction, 9(5), 48.

Synopsis:
This study presents a mobile obstacle detection system designed for visually impaired users. The system uses computer vision and a YOLO-based object detector to identify objects in the environment. The researchers created the Detectra dataset, containing 7,600 images and 76 object classes. The mobile application also provides auditory and haptic feedback to communicate detected obstacles to the user.

Reliability:
This is a strong academic source because it is a recent peer-reviewed journal article. The researchers explain their dataset, object detection model, implementation, evaluation metrics, and mobile application. It is especially relevant because the subject closely matches this tutorial.

[2] Lin, Lee, and Chiang (2017)

Citation:
Lin, B.-S., Lee, C.-C., & Chiang, P.-Y. (2017). Simple Smartphone-Based Guiding System for Visually Impaired People. Sensors, 17(6), 1371.

Synopsis:
This paper presents a smartphone-based guiding system for visually impaired users. The smartphone captures visual information from the environment, and object recognition can be performed using Faster R-CNN or YOLO. The system was designed to support both online and offline operation. This research is useful because it provides an earlier example of applying deep-learning-based object recognition to smartphone navigation assistance.

Reliability:
This is a peer-reviewed article published in Sensors. The researchers describe the architecture of the system, recognition methods, operating modes, and experimental results. It also provides a useful comparison with more recent mobile computer vision systems.

[3] More et al. (2025)

Citation:
More, S. S., Patil, N., Lobo, V. B., Shet, N., Goswami, D., & Rane, P. (2025). Empowering the Visually Impaired: YOLOv8-Based Object Detection in Android Applications. Procedia Computer Science, 252, 457-469.

Synopsis:
This study investigates the use of YOLOv8 for real-time object detection on Android devices. The researchers convert YOLOv8 into TensorFlow Lite so the model can run directly on mobile hardware. Different model sizes and input resolutions are compared to study the relationship between detection accuracy and inference speed.

Reliability:
This is an academic article published in Procedia Computer Science by Elsevier. The paper reports quantitative performance measurements such as detection accuracy and inference time, making it useful for analyzing the trade-off between speed and accuracy on mobile devices.

[4] Wang et al. (2024)

Citation:
Wang, W., Jing, B., Yu, X., Sun, Y., Yang, L., & Wang, C. (2024). YOLO-OD: Obstacle Detection for Visually Impaired Navigation Assistance. Sensors, 24(23), 7621.

Synopsis:
This paper introduces YOLO-OD, an object detection method developed specifically for navigation assistance for visually impaired users. The approach includes architectural changes intended to improve the recognition of differently sized, partially occluded, and difficult-to-detect obstacles in complex outdoor environments.

Reliability:
This is a recent peer-reviewed article published in Sensors. The paper describes the proposed architecture, compares it with other detection approaches, and reports experimental results. It is especially useful for the technical sections of this tutorial.

[5] Gharani and Karimi (2017)

Citation:
Gharani, P., & Karimi, H. A. (2017). Context-Aware Obstacle Detection for Navigation by Visually Impaired. Image and Vision Computing, 64, 103-115.

Synopsis:
This research presents a smartphone-based obstacle detection approach for indoor navigation. The method processes consecutive video frames, computes optical flow, and tracks feature points to identify obstacles. It also considers the direction of the user's movement so the system can focus on important regions of the image.

Reliability:
This article was published in the peer-reviewed journal Image and Vision Computing. It is valuable because it presents a different computer vision approach from YOLO-based object detection and shows how motion and contextual information can contribute to obstacle detection.

[6] Panchal et al. (2021)

Citation:
Panchal, K. U., Khara, D. C., Gari, T. J., & Chavan, V. (2021). Companion: Easy Navigation App for Visually Impaired Persons. 2021 International Conference on Intelligent Technologies (CONIT), IEEE.

Synopsis:
This work presents an Android navigation application that combines YOLOv3 object detection, depth estimation, and text-to-speech. The system attempts to determine which detected object is closest and most relevant instead of announcing every object in the scene. Depth information and bounding-box size are used to help prioritize obstacles before audio feedback is produced.

Reliability:
This paper was published in the IEEE International Conference on Intelligent Technologies. It is useful because it presents an implemented mobile system that combines object detection, depth estimation, and audio feedback.
